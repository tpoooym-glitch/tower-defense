# 🏰 Tower Defense V1

เกม Tower Defense เวอร์ชันแรกสำหรับเล่นบนเว็บ

## เล่นเกม

เปิด `index.html`

## ดาวน์โหลดเกม

ถ้าเปิดผ่าน GitHub Pages ให้เข้า `download.html` แล้วกด **ดาวน์โหลดเกม** เพื่อบันทึกเป็น `Tower-Defense-V1.html` จากนั้นเปิดไฟล์ด้วย Chrome ได้ทันที

หรือดาวน์โหลดทั้งโปรเจกต์จาก GitHub ด้วย **Code → Download ZIP**

## ระบบใน V1

- Tower Defense แบบเล่นได้จริง
- ศัตรูเดินตามเส้นทาง
- ระบบเงินและ HP ฐาน
- Wave 1–10
- Boss ทุก 5 Wave
- Tower และกระสุนยิงอัตโนมัติ
- ระบบชนะ/แพ้
